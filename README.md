# Velora

Velora is a lightweight command-line utility for local file intelligence.

It helps you scan directories, search for files, detect duplicates,
and inspect basic storage statistics without external dependencies.

## Features

- Recursive directory scanning
- File pattern search
- Duplicate detection
- SHA-256 based file comparison
- Directory statistics
- Zero external dependencies
- Cross-platform
- Simple CLI interface

## Requirements

Python 3.9+
